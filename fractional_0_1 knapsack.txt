
def knapsack(capacity, weights, profits, n):

    dp = [[0 for j in range(capacity + 1)]
          for i in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, capacity + 1):

            if weights[i - 1] <= w:
                dp[i][w] = max(
                    profits[i - 1] + dp[i - 1][w - weights[i - 1]],
                    dp[i - 1][w]
                )
            else:
                dp[i][w] = dp[i - 1][w]

    return dp[n][capacity]


n = int(input("Enter number of items: "))

profits = []
weights = []

for i in range(n):
    p = int(input("Enter profit: "))
    w = int(input("Enter weight: "))

    profits.append(p)
    weights.append(w)

capacity = int(input("Enter knapsack capacity: "))

result = knapsack(capacity, weights, profits, n)

print("Maximum profit:", result)


We use Dynamic Programming because we solve smaller subproblems and store their results in a 2D table (dp) to avoid solving the same subproblems repeatedly.

The main condition is:
\[
dp[i][w] = \max(
p_i + dp[i-1][w-w_i],
dp[i-1][w])
\]
